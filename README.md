# Mobilitat quotidiana — Barcelona

Una pàgina breu sobre els hàbits de mobilitat diaris. Està pensada per llegir-se amb calma, amb una tipografia Special Gothic Expanded One, molt d'espai, navegació fixa i un petit globus que acompanya el desplaçament.

## Fitxers

- `index.html`: contingut i estructura de la pàgina.
- `style.css`: identitat visual, espaiat i adaptació a mòbil.
- `script.js`: menú mòbil, progrés del desplaçament, aparició de seccions i gir del globus segons la direcció del scroll.

## Obrir la web

Obre `index.html` en qualsevol navegador modern.
