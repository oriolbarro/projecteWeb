# Camins de cada dia — Barcelona

Una web editorial i interactiva basada en la investigació sobre els hàbits de mobilitat sostenible a Barcelona. La identitat visual s'inspira en una estètica contemplativa i orgànica: espai, textures topogràfiques i una brúixola creada per al projecte.

## Fitxers

- `index.html`: contingut i estructura de la pàgina.
- `style.css`: identitat visual adaptable a mòbil i escriptori.
- `script.js`: registre de trajectes interactiu.

## Obrir la web

Obre `index.html` en qualsevol navegador modern. El registre calcula els quilòmetres introduïts durant la sessió i no envia ni desa dades en línia.
