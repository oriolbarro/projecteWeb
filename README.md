# Camins de cada dia — Barcelona

Web editorial i interactiva sobre mobilitat quotidiana a Barcelona.

## Web publicada
- Portada: https://oriolbarro.github.io/projecteWeb/
- Mapa: https://oriolbarro.github.io/projecteWeb/mapa.html
- PDF per a l'entrega: https://oriolbarro.github.io/projecteWeb/output/pdf/Entrega-Camins-de-cada-dia.pdf
- Repositori: https://github.com/oriolbarro/projecteWeb

## Obrir en local
Obre `index.html` en un navegador modern. La pàgina del mapa necessita connexió a internet per carregar la cartografia i alguns serveis de rutes.

## Estructura
- `index.html`, `style.css`, `script.js`: portada i interaccions.
- `mapa.html`, `mapa.css`, `mapa.js`: mapa, filtres i recorreguts.
- `SOUL.md`, `CONTEXT.md`, `INSTRUCTIONS.md`: propòsit, context i criteris per continuar el projecte.
- `LOG.md`: registre de canvis i verificacions.
- `docs/loops/`: fitxes de procés per scroll.

## Procés documentat
Les fitxes descriuen què decideix Oriol, què s'ha implementat i qui verifica cada resultat. La revisió visual final s'ha d'anotar quan es faci; les estimacions de temps i els serveis de transport s'han de comprovar abans d'afirmar que una ruta és actual o òptima.
